①ターミナル１
cd ~/Isaac-GR00T
source .venv/bin/activate
NO_ALBUMENTATIONS_UPDATE=1 HF_HUB_OFFLINE=1 \
  ~/Isaac-GR00T/.venv/bin/python gr00t/eval/run_gr00t_server.py \
  --embodiment-tag NEW_EMBODIMENT \
  --model-path /media/tmc/DATA/data/GR00T/N1.7/n710/checkpoint-50000 \
  --device cuda:0 \
  --host 0.0.0.0 \
  --port 5555

# [高速化フラグは撤去済み] TensorRT + --compute-dtype float16 は使用禁止。
#   理由(2026-07-02 20260702_075728のログで確認):
#     - float16のTensorRT(action_head)化で拡散ヘッド出力が全チャンネルNaNになった。
#     - clamp_action_step=False だったためNaNがそのままモータへ送られ、ロボットが暴走。
#     - さらに初回コンパイルが推論内で56秒走り、その間ロボットが停止した(=「長時間停止」の正体)。
#   GR00Tの拡散ヘッドはbfloat16前提で、float16(狭いダイナミックレンジ)と相性が悪くNaN化する。
#   → 高速化は既定の bfloat16 / PyTorch(TensorRTなし) が安全な基準構成。
#   再挑戦するなら先にNaN検出ガード(送信前にNaNなら停止)を eval 側へ入れてから。
#   参考: 素の構成の実測は推論約128ms / actual_action_send_hz_mean 約14.6Hz。
